# AMAX Price Quote

Import this repository into your agent as a skill. [SKILL.md](SKILL.md) is at the root, with `references/` and `scripts/` alongside it. No ZIP is required.

```sh
git clone https://github.com/Amax-Travel/amax-price-quote.git
```

Requires Python 3.10+ and the existing local AMAX sales gatekeeper. CRM stage updates require an authorized Twenty connection. This is a test version; verify the complete workflow in your agent before production adoption. No client data or credentials are included.
